# Local development dependencies

Copy your compatible Overgrown Apoli jar to `libs/apoli.jar` and Overgrown Origins jar to `libs/origins.jar` before building or running the development server. These jars are intentionally excluded from Git.

The original development build used Apoli 1.90.0 (keybind fix v6) and Origins 1.41.0 for Minecraft 1.20.1.
