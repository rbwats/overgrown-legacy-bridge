# What this mod fixes, and what it doesn't

Overgrown Origins is a rewrite of the original Origins mod, so many custom origins made for the old version (Origins 1.10.0 on Minecraft 1.20.1) don't load on it or behave differently. This mod fixes that automatically when the game loads your data packs, so you don't have to edit them. It translates old pack files into a form Overgrown understands, restores features and powers that Overgrown dropped or changed, and makes the math and old commands work as they used to. It also carries existing players' origins and progress over to Overgrown, so nobody has to pick their origin again. Every release is tested on a server and a client before it's published.

It can't fix everything. Add-on mods written in Java for the old Origins need to be updated by their authors, and power types that come from other add-ons only work if those add-ons support Overgrown. Only Minecraft 1.20.1 packs are supported. A few things behave close to the original rather than exactly the same. Visual effects, HUDs and key presses haven't been checked by playing the game yet. Install the mod on the server and on every player's game, and skip version 0.5.0, which doesn't start.
